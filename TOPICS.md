# Topic vocabulary

Fixed set — do not invent new topics casually. Domain + lifecycle + owner.

**Domain:** `tool` · `brain` · `infra` · `project`

**Lifecycle:** `active` · `dormant` · `archive`

**Owner:** `agent` · `gitggod`

`dormant` means "kept on purpose, not currently moving". `archive` means
"historical record, do not start work from here".
